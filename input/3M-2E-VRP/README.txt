3M-2E-VRP benchmark instances

Files use the naming convention:
3M-Cb-<depots>-<parking locations>-<customers>-<sample>.txt

The stochastic paper uses the 50-customer instances as the medium class and
the 100-customer instances as the large class. Instance selection is controlled
by numberOfDepots, numberOfParkingLocations, customerCountStart/End, and
sampleIndexStart/End in the root config.properties file.
